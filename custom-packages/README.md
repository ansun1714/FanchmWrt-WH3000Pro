# 后续自定义软件包

第一版没有把以下包硬塞进固件：

- msd_lite
- rtp2httpd
- luci-app-iptv-manager / IPTV Combo

原因是这次首先验证 FanchmWrt 原生 WH3000 Pro eMMC 支持和 QModem。

等第一版成功启动后，把你之前使用的：
`custom-packages/luci-app-iptv-manager`
完整目录上传/放回这里，再加入编译。

MSD Lite 可参考：
https://github.com/ximiTech/msd_lite

rtp2httpd：
https://github.com/stackia/rtp2httpd
